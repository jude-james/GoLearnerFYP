# Welcome!

This is the first of a series of topics covering Go's fundamentals. Each topic will be structured similar to this page. The topic may be a lesson, a small multiple choice question, or an exercise challenge.

## The Navbar

At the top of the page, you can see the current topic title, the current chapter progress, and navigation buttons between topics. Once you're done with this page, click the right arrow to move onto the next!

Above the tutorial navbar remains the website navbar, click the tutorial button again to return to the contents page. To hide both navbars, scroll to the bottom of the page, which aligns so that the content and code editor take up the full height.

## The Code Editor

On the right half of the page you can see the code editor window. Each topic will start with an example Go program, feel free to play around and experiment with the code. It's worth noting, any changes you make on this page will persist, you can move on to the next page and come back to resume your coding for this specific editor window.

You'll see 4 buttons below the editor:

- **Run**: Runs the program (It may take a few seconds)
- **Terminate**: Terminates the program, in case you're stuck in an infinite loop for instance (The run button will activate again once the program has terminated)
- **Reset**: Resets the code to the original example for this topic
- **Copy**: Copies the code to your clipboard 

Below the editor is the console output window, here you will see your programs output. Click *run* and you should see the welcome message printed to the console.

> **Note:** There is a 10 second timeout limit, if your program runs longer than that it will be killed.
